# Glossary: English ↔ Bangla (0A.10-T6)

Use these words everywhere in the UI. If a word is missing, add it here in the same PR that first uses it.
**Status:** proposed by development; **the owner or a native reader confirms** (or corrects) each row in the
release review (`ENVIRONMENTS_AND_RELEASES.md` rule 8). Corrections change the row and every translation that uses it.

## Style

- Address the user politely with **আপনি** and the polite imperative (করুন, দেখুন), never তুমি.
- Bangla sentences end with **।**; keep English punctuation inside English words and numbers.
- Digits and number, money and date formats: decided in 0A.11 (locale settings, Bangla digit input).
- Language names are always shown in their own language: **English**, **বাংলা**.
- Keep loan words that users already say (লিড, ফলো-আপ, অ্যাপ) rather than rare formal Bangla.
